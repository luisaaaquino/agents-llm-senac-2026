# Avaliador v1

Avalie o parecer final do lote com critérios objetivos.

Para cada critério responda booleano:
- `cita_artigo`: o parecer cita o artigo da política quando aplicável?
- `cita_valor`: o parecer cita os valores relevantes?
- `conclui`: o parecer apresenta uma conclusão clara?

A aprovação só ocorre quando os três critérios são verdadeiros.
Se algum critério falhar, informe uma correção objetiva.
